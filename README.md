### Question 1

The default value of a float is 0.0, and the default value of an int is 0. The default value of a bool is false, and the default value of a string is null. 

### Question 2

The Update() method is called automatically by Unity every frame when the script is active. We do not need to call it ourselves. It helps update the game continuously. 

### Question 3

The TimerText class uses the Timer class to get the remaining time. In the Update() method, it checks the time and updates the text on the screen. This allows the player to see the countdown while playing the game.
